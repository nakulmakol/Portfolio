# Nakul Makol — Portfolio

Built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, Geist font.

## Quick Start
```bash
npm install
npm run dev        # http://localhost:3000
```

## Deploy
```bash
git init && git add . && git commit -m "init"
# push to GitHub → import to Vercel → Deploy
```

## Add your resume
Drop `resume.pdf` into `/public/resume.pdf`.
